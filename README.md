# Devarshi Dalal

I study mathematical biology, neuroscience, and business at the University of Michigan. I build tools for healthcare and work on ML projects where the quality of the input signal matters as much as the model.

### Projects

- **[EEG/fMRI signal validation](https://github.com/Dev1625/eeg-fmri-signal-validation)** · Compare EEG artifact-removal methods and test whether the cleaned signal preserves what you care about. Includes a runnable synthetic example.
- **[TapMed dose log](https://github.com/Dev1625/tapmed-dose-log)** · A browser demo of the medication logging workflow I built for TapMed. Try a simulated NFC tap, log a dose offline, and see how a correction changes the history. [Live demo](https://dev1625.github.io/tapmed-dose-log/)
- **[Healthcare evidence explorer](https://github.com/Dev1625/healthcare-evidence-explorer)** · A pandas walkthrough and web app for joining messy source tables, handling missing values, and tracing each record back to its source.
- **[Image quality ML](https://github.com/Dev1625/image-quality-ml)** · A small image QC experiment with generated examples, grouped validation, and a simple baseline you can run locally.

I mostly work in Python and TypeScript/JavaScript. The project READMEs cover how to run each example and the design choices behind it.
